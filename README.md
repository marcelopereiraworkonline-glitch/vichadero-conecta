# Vichadero Conecta

Red social comunitaria de Vichadero (Uruguay), creada con Next.js y Supabase.

## Configuración

Instalá dependencias con `npm install`. En `.env.local` configurá `NEXT_PUBLIC_SUPABASE_URL` y `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`. Ejecutá `npm run dev`.

La base de datos se crea con `supabase/schema.sql`. Nunca subas claves privadas.
